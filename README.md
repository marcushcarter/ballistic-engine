### Clone Repository
```bash
git clone --recursive https://github.com/marcushcarter/lumen.git Lumen
cd Lumen
git submodule update --init --recursive
```

**Build**
```bash
# Compile with gcc (C++)
mkdir build
cd build
cmake ..
cmake --build .
```
